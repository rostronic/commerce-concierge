# Sizing & Fit

## General fit
Our shoes run **true to size** in US men's sizing. The Trailblazer trail runners fit
slightly narrow — customers with wide feet should order a **half size up**.

## Hiking boots
The Summit Hiking Boot runs **a half size large**. Order a half size down unless you plan
to wear thick wool socks.

## Half sizes and widths
Half sizes are stocked from 7 through 13. We do not currently offer width variants (D
width only).

## If the size is wrong
Size exchanges ship free in both directions — see the Returns policy for the exchange
terms.
